Three ways to fit the range picker on a phone

Drawn at 390pt. The problem today is that the desktop layout stacks: five presets wrap onto two lines inside a pill, then a second card holds two dates and Apply — four rows of chrome before the first number. Every tap target below is at least 44pt.

1a

Scrolling chips + sheet

Presets never wrap — they scroll sideways, which is the phone convention for a filter row. Custom dates move into a sheet, so the default case is one row tall and the numbers start higher up the page.
