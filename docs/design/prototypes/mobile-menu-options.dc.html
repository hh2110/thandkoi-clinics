Why the menu reads as "you're in Donate"

The current page is already marked — .primary-nav__list a[aria-current="page"] in components.css sets color: var(--color-brand) plus an underline. The problem is the colour: --color-brand stays #086c7e in the dark theme, sitting on a #0a3e48 drawer — about 1.9:1 contrast, far below the 4.5:1 WCAG AA minimum, so the marker is invisible in the exact screenshot Dawood sent. (Pale aqua #a0e0e8 on the same drawer measures 8.0:1; brand teal on the light theme's white is already 6.1:1, which is why this only bites in dark mode.) Meanwhile the amber .button--donate is the last <li> of the same list — the one filled thing in the drawer.

So: give the current page a marker that survives both themes, and stop the only filled element being the one that isn't a page. All three keep Donate one tap away; Dawood's second suggestion — donate links in body copy — is worth doing whichever wins. Drawers below are drawn with the real values: list padding --space-1 --space-2 --space-2, --space-1 gap, links 600 weight with padding-block: --space-1, buttons 8px radius.

1a

CSS only

No template change. Point the existing aria-current rule at a theme-aware token instead of --color-brand (pale aqua on dark, brand teal on light), add weight 700, and swap .button--donate for the existing .button--outline treatment in amber. Fill now only ever means "current page".
