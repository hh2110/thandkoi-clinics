{% load static %}{% comment %} Link-preview (OpenGraph + Twitter) image tags for one page. Usage, inside a page template's `social_image_tags` block: {% block social_image_tags %} {% include "partials/social_card.html" with card="og-donate.jpg" alt=... %} {% endblock %} `card` is a filename under static/images/og/, all of which are generated by scripts/generate_og_cards.py — see that script for the card specs and for why the output has to be a <300 KB 1200x630 JPEG (WhatsApp drops anything over 600 KB silently, which is what used to happen to the old 786 KB PNG card). The width/height/type tags are not decorative: WhatsApp and Facebook use them to decide whether to render the large card or a small square thumbnail, and declaring them means the platform does not have to fetch the image before it can lay the preview out. {% endcomment %} {% with card_url=request.scheme|add:"://"|add:request.get_host %} {% endwith %}
